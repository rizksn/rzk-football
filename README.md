# 🧠 RZK Football – Draft Cockpit (Frontend)

This is the official frontend for **RZK Football**, a modern fantasy football mock draft simulator and AI-powered draft preparation tool.

Built from scratch as a full-stack fantasy experience, the frontend acts as your **personal draft command center** — immersive, customizable, and data-driven.

---

## 🚀 Key Features

- ⚡ Live mock drafting against a modular AI engine
- 🎮 Dynamic 3D-inspired multi-panel UI (roster, queue, player data)
- 🧠 LLM-based draft advisor (in development)
- 🧱 Fully customizable draft layouts and overlays
- 🗂️ Format-aware logic (1QB, Superflex, Keeper, Dynasty, etc.)
- 🔐 Premium-tier toggle for advanced AI modes and league settings
- 🌀 Real-time syncing with backend simulation engine

## 🧠 How It Works

This frontend is powered by:

- A real-time draft board built in **React + Tailwind**
- Interactive panels for:
  - Player pool
  - Roster
  - Queue
  - Stats and insights
- Click-driven actions (claim slot, start draft, view player)
- Tight API integration with the backend draft engine (`rzk-football-anubis`)

---

## 🛠️ Tech Stack

- **Next.js / React / TypeScript**
- **Tailwind CSS**
- **Firebase (Auth)**
- **FastAPI backend (see [`rzk-football-anubis`](https://github.com/rizksn/rzk-football-anubis))**
- **LLM integration** via DeepSeek (coming soon)
